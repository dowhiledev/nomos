# Examples

This folder contains conceptual examples for Nomos vNext. These are developer-first, code-centric samples illustrating the intended API and runtime behaviors described in BRAINSTORM.md. They are not runnable yet; they demonstrate how you would compose graphs, tools, and servers once the core libraries exist.

- See `conceptual_agent/` for a comprehensive end-to-end example showcasing:
  - Event-sourced, async, streaming orchestration
  - Multimodal I/O (text/image/audio)
  - Tools with progress, timeouts, and cancellation
  - Interrupts and barge-in
  - Multi-agent team coordination
  - Optional SSE/WS server
